# Agentic projects

## [Research Agent](https://github.com/ramelgonzz/ai-engineering/tree/main/research-agent)
Plans a research strategy, searches the web, reads sources, cross-checks facts, and produces a cited report.
Features planning, tool use, citation handling, self-critique loops.

## [Code Fixing Agent](https://github.com/ramelgonzz/ai-engineering/tree/main/code-fixing-agent)
A self-correcting coding agent: write code → run tests in a sandboxed
subprocess → read the failure output → patch → repeat, with a hard
iteration cap and rollback to the best attempt if the budget runs out.
